منصة التقويم والتحسين المدرسي V3.1

- تعمل محليًا في المتصفح ولا تحتوي على مشرف أو تسجيل دخول.
- البيانات المنظمة تحفظ على الجهاز، والملفات تحفظ في IndexedDB داخل المتصفح.
- استخدم النسخ الاحتياطي دوريًا من صفحة الإعدادات.
- للنشر على GitHub Pages: ارفع جميع محتويات هذا المجلد إلى جذر المستودع.
- لاستخدام التثبيت PWA وService Worker يجب فتحها عبر https أو localhost، وليس file://.

مرجع التقويم: معايير التقويم والتصنيف والاعتماد المدرسي، الإصدار الثاني 2026م.
مرجع نافس: وثيقة نواتج التعلم للاختبارات الوطنية 2026م، ودليل المدرسة الإرشادي لنافس 2026.


V3.1 – عقل المنصة:
- محرك تحليل موحد للتقويم الذاتي ونافس والخطة التشغيلية والرضا وخطط التحسين.
- تحليل SWOT تلقائي + مدخلات فريق المدرسة.
- ترتيب الأولويات واقتراح حلول قابلة للتحويل إلى خطة تحسين.
- فصل نسبة اكتمال التقويم عن درجة الأداء ومؤشر الجاهزية الداخلي.
- الخطة التشغيلية: مؤشرات، مستهدفات، فعلي، مخاطر، أسباب جذرية، وتحويل البنود المتعثرة إلى تحسين.
