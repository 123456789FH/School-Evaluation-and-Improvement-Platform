منصة التقويم والتحسين المدرسي — V4.2 Premium UI
================================================

هذا تحديث للمنصة الحقيقية، وليس صورة أو نموذجًا ثابتًا.
لا يغير محرك التحليل SchoolBrain ولا التخزين Store ولا التصدير؛ التعديل واجهة بصرية وتفاعلية فوق النسخة الحالية.

الملفات التي يجب رفعها إلى المستودع:
1) index.html                   ← استبدال الموجود
2) sw.js                        ← استبدال الموجود
3) assets/css/styles.css        ← استبدال الموجود
4) assets/js/v4-ui.js           ← ملف جديد يضاف داخل assets/js

مهم جدًا:
- لا تحذفي assets/js/app.js أو data.js أو engine.js أو storage.js أو document-intelligence.js أو report-export.js.
- لا تحذفي مجلد assets/images؛ الواجهة تستخدم leadership-hero.png الموجود أصلًا في المستودع.
- بعد الرفع افتحي الرابط مرة واحدة مع ?v=4.2 لتجاوز الكاش، مثال:
  https://123456789fh.github.io/School-Evaluation-and-Improvement-Platform/?v=4.2

أبرز التغييرات:
- قائمة جانبية يمين أكثر رسمية وترتيبًا.
- شريط علوي منظم بروابط رئيسية سريعة.
- Hero احترافي كبير لكل قسم.
- في القيادة المدرسية تستخدم الصورة الأصلية leadership-hero.png داخل الواجهة الفعلية.
- أهداف القيادة تظهر كبطاقات داخل Hero.
- بطاقات الأدوار القيادية تفاعلية وتفتح المهام الحقيقية.
- إعادة ترتيب القيادة: الأدوار أولًا ثم المهام العامة ثم الخطة والمؤشرات.
- أزرار PDF وWord وExcel وإضافة المبادرة أصبحت شريط عمليات حقيقي أسفل مؤشرات القيادة.
- تحسين بطاقات KPI والألوان والمسافات والتجاوب مع الجوال والآيباد.
- تحديث Service Worker إلى cache جديد V4.2 مع Network First للملفات الحرجة.
